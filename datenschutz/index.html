Wir selbst haben keinen Zugriff auf diese Logfiles. Details: GitHub Privacy Statement.

Keine Cookies, nur lokaler Speicher für Ihre Auswahl

Diese Website setzt keine Cookies. Im lokalen Speicher Ihres Browsers (localStorage) wird nur dann etwas abgelegt, wenn Sie die jeweilige Funktion selbst nutzen:

  • Design: wenn Sie zwischen hellem und dunklem Design umschalten, merkt sich Ihr Browser diese Wahl.
  • Warenkorb ID: wenn Sie im Shop etwas in den Warenkorb legen, damit Ihr Warenkorb beim nächsten Besuch noch da ist. Diese ID wird nur an Fourthwall übermittelt, um den Warenkorb zu laden (siehe Shop).

Diese Speicherung ist für die von Ihnen ausdrücklich gewünschte Funktion unbedingt erforderlich (§ 25 Abs. 2 Nr. 2 TDDDG). Die Einträge bleiben in Ihrem Browser, bis Sie sie löschen. Das geht jederzeit über die Einstellungen Ihres Browsers.
